git diff показывает разницу между двумя состояниями проекта
git show выводит подробную информацию об объекте
git log выводит историю коммитов в репозитории (с хэшами, авторами, датами и сообщениями)
git log -s ' ' показывает только те коммиты, в которых изменение кода повлекло за собой добавление или удаление указанной строки
git blame для каждой строки файла выводит информацию о последнем коммите, который её изменил
