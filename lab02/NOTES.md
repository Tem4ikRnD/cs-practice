Рабочая папка - это папка для работы с файлами проекта
Индекс - это область для подготовки изменений перед отправкой коммита
Коммит - это сохранение состояния проекта

Git - это система контроля версий
GitHub - это облачный сервис для совместной работы над проектами
Команда git diff показывает разницу между рабочей директорией и индексом
А команда git diff --staged сравнивает индекс с последним коммитом
