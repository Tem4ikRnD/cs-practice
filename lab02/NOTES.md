Рабочая папка - это папка для работы с файлами проекта
Индекс - это область для подготовки изменений перед отправкой коммита
Коммит - это сохранение состояния проекта

Git - это система контроля версий
GitHub - это облачный сервис для совместной работы над проектами
Команда git diff показывает разницу между рабочей директорией и индексом
А команда git diff --staged сравнивает индекс с последним коммитом

Использованные команды:
git status показывает текущее состояние репозитория (изменения с последнего коммита)
git diff показывает разницу между рабочей директорией и индексом
git diff --staged сравнивает индекс с последним коммитом

Ветки:
Ветка - указатель на конкретный коммит (показывает конец линии разработки)
При новом коммите указатель автоматически сдвигается на него
Слияние — это процесс объединения изменений из одной ветки в другую
